Selamat datang

Ini installer KasirGo. Isi kredensial database PostgreSQL lalu klik Next untuk memulihkan seluruh data (produk, transaksi, pelanggan, karyawan, dan akun login termasuk password) ke server baru.

  • Target: PostgreSQL (mis. instance Supabase self-host / VPS).
  • Data diambil dari paket backup database/*.sql.
  • Akun login ikut dipulihkan apa adanya (hash password ter-copy).
